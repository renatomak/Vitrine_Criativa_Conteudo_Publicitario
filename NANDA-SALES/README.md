# Nanda

Influencer de IA com perfil mais evangélico. Responsável pelos demais produtos do projeto, incluindo moda, beleza, casa, limpeza, livros e hobbies.

Os produtos ficam diretamente em `produtos/nanda/codigo-do-produto/`, com suas imagens, vídeos, descrições e metadados.

Na criação de novos conteúdos, respeitar o perfil evangélico definido para a personagem. A organização das pastas preserva os materiais anteriores; os roteiros e criativos existentes devem ser avaliados quanto à adequação ao perfil antes de uma nova publicação.
